# Welche APK installieren?

Installiere:

```text
AniSentinel-v0.24.2-DIAGNOSETEST-V24-PROVIDER-PROBES.apk
```

Die APK ist ein Diagnosebuild. Crunchyroll-/ADN-Probes und der manuelle historische Providercheck
sind experimentell. Es gibt keinen Login, keine Wiedergabe, keinen Download und keine DRM-Funktion.
