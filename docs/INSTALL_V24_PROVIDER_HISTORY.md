# Installation – AniSentinel v0.24.4

1. `AniSentinel-v0.24.4-DIAGNOSETEST.apk` auf das Android-Gerät kopieren.
2. Installation aus unbekannten Quellen für den verwendeten Dateimanager erlauben.
3. APK installieren beziehungsweise die vorhandene Diagnoseversion aktualisieren.
4. App öffnen. Die Room-Migration erhält den vorhandenen Kalenderbestand.
5. Im Kalender einen Monat wählen und „Historie für … laden“ verwenden.

Der Diagnosebuild benötigt eine Internetverbindung für AniWorld, JustWatch sowie
die anonymen öffentlichen Crunchyroll-/ADN-Metadatenwege. Er enthält keine
Login-, Playback-, Stream-, Download- oder DRM-Funktion.
