# Installation – AniSentinel v0.24.5

1. `AniSentinel-v0.24.5-DIAGNOSETEST.apk` installieren beziehungsweise über die vorhandene Diagnoseversion aktualisieren.
2. App starten; vorhandene Room-, Favoriten-, Kalender- und Historienbestände bleiben erhalten.
3. Eine Crunchyroll-Serie über Suche/Entdecken öffnen oder im Kalender die Historie des gewählten Monats laden.
4. Die Diagnose zeigt nur sicher aufgelöste Series-IDs und bestätigte Episodendaten an.

Kein Login, Playback, Streaming, Download oder DRM-Zugriff ist enthalten.
